# 🖥️ ScreenScanner

> **100% Offline & Private Screen-OCR for Windows**  
> Inspiriert von Samsungs / Googles *Circle to Search* – ganz ohne Cloud, ohne externe Server und ohne Drittanbieter-APIs.

---

### ✨ Features

- 🔒 **100% Datenschutz & Offline:** Verwendet ausschließlich die native Windows-eigene OCR-Engine (WinRT/UWP). Keine Daten verlassen deinen Rechner.
- ⌨️ **Globaler Hotkey:** Mit einem Tastendruck (z. B. `Strg + Shift + S`) sofort aus jeder Anwendung heraus einsatzbereit.
- 🎯 **Region-Auswahl:** Bildschirmbereich mit der Maus markieren – Text wird in Millisekunden extrahiert.
- 📋 **Auto-Clipboard:** Der erkannte Text landet sofort in deiner Zwischenablage (`Strg + V`).
- 🤖 **Zukunftssicher:** Vorbereitet für lokale KI-Integrationen (z. B. via Ollama für Zusammenfassungen, Übersetzungen oder Q&A).

---

### 💡 Warum ScreenScanner?
Moderne Features wie Samsungs *Circle to Search* oder Google Lens sind praktisch, übertragen Bilddaten jedoch an Cloud-Server. **ScreenScanner** bringt denselben Workflow auf deinen Windows-PC – komplett lokal, schlank und sicher.
